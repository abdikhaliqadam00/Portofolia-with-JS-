    Process

    How I work on an idea.

    1. Break it down

      Split the problem into small tasks I can finish one at a time.

    2. Sketch it

      Plan the layout and labels before writing any code.

    3. Build it

      Write clean HTML and CSS, then add behaviour with JavaScript.

    4. Test it

      Check it on phone and desktop, then fix what I find.
